# cex-desk

二手遊戲價格追蹤工具的資料骨幹。自動抓取公開商品列表、比對變動，並產生一個手機可看的頁面。

## 內容

| 路徑 | 用途 |
|---|---|
| `scripts/` | 抓取與比對腳本。**由本機自動同步過來，請不要直接改這裡**（會被下次同步覆蓋） |
| `state/` | 執行狀態：上次成功時間、比對基準。機器讀寫用，不建議手動改 |
| `web/index.html` | 手機頁面的原始檔 |
| `data` 分支 | 頁面與資料本體（GitHub Pages 的來源） |

## 需求

Node.js 24 以上。**沒有 npm 依賴**（只用 `node:` 內建模組）。
需要環境變數 `TELEGRAM_BOT_TOKEN`（推播用）與 `TELEGRAM_CHAT_ID`（收訊對象）。

## 運作方式

- **主動端**：一台本機每天兩次抓取、載入本機資料庫、比對變動，並更新 `state/` 與 `data` 分支。
- **備援**：GitHub Actions 每天三次檢查 `state/heartbeat.json`。**主動端 24 小時內有成功抓取就直接結束**；超過才自己抓一次、比對、推播。

備援只在主動端失效時才動作，所以平時不消耗資源。
